# Документация по порталу `Neftyanik`

## Назначение

Портал предназначен для ведения работы садового товарищества:

- учет членов товарищества;
- учет участков и владельцев;
- учет электросчетчиков, тарифов и показаний;
- начисления по электроэнергии и членским взносам;
- прием платежей и контроль долгов/переплат;
- учет расходов товарищества;
- базовое администрирование пользователей.

## Роли в системе

### `Administrator`

Полный доступ к административным разделам:

- пользователи и роли;
- члены товарищества;
- участки;
- электросчетчики и тарифы;
- финансы;
- системные настройки.

### `Accountant`

Доступ к рабочим разделам учета:

- члены товарищества;
- участки;
- электроэнергия;
- начисления;
- платежи;
- расходы;
- финансовые сводки.

### `Member`

Доступ только к своим данным:

- личный кабинет;
- свои участки;
- свои начисления и платежи;
- свой баланс;
- передача показаний счетчика;
- изменение контактных данных и пароля.

## Основные разделы портала

### Главная страница

Показывает краткое описание портала и кнопки перехода:

- `Личный кабинет` — для членов товарищества;
- `Панель администратора` — для администратора и бухгалтера.

### `Администрирование`

Содержит сводную информацию:

- доступность базы данных;
- количество пользователей;
- количество ролей;
- количество примененных миграций;
- текущее окружение приложения.

### `Участки`

Позволяет:

- создавать участки;
- редактировать карточку участка;
- архивировать участок;
- назначать и завершать владение участком;
- просматривать карточку участка;
- работать с начислениями и электричеством по участку.

### `Члены товарищества`

Позволяет:

- создавать карточки членов товарищества;
- редактировать данные;
- архивировать записи;
- просматривать закрепленные участки;
- создавать начисления;
- регистрировать платежи;
- управлять учетной записью пользователя;
- сбрасывать пароль и назначать роли.

### `Электроэнергия`

В административной части доступны:

- счетчики;
- показания счетчиков;
- тарифы для товарищества;
- индивидуальные тарифы членов;
- общий счетчик товарищества.

Поддерживаются:

- индивидуальные и общие счетчики;
- однотарифный и день/ночь режимы;
- ввод начальных показаний;
- создание новых показаний;
- просмотр истории показаний.

### `Финансы`

Раздел предназначен для контроля:

- кассы;
- начислений за год;
- задолженности;
- переплат;
- участков с долгом и без долга;
- фильтрации и поиска по участкам.

Дополнительно доступны подразделы:

- `Расходы`;
- `Расходы электроэнергии`;
- `Настройки финансов`.

## Как работает портал в целом

### 1. Подготовка доступа

Для локального создания администратора используйте инструкцию из файла:

- `docs/DEVELOPMENT_AUTH_BOOTSTRAP.md`

После первого входа пользователь с временным паролем должен сменить пароль.

### 2. Базовая настройка

Обычно работа начинается так:

1. создать или проверить учетную запись администратора;
2. создать карточки членов товарищества;
3. создать участки;
4. назначить владельцев участкам;
5. настроить счетчики и тарифы;
6. начать ввод показаний, начислений и платежей.

### 3. Работа с участками и владельцами

Рекомендуемый порядок:

1. создать участок;
2. открыть раздел владения;
3. назначить владельца;
4. при смене владельца завершить текущее владение и создать новое;
5. не использовать удаление для исторически значимых записей.

### 4. Работа с электроэнергией

Обычный сценарий:

1. создать или назначить счетчик;
2. указать тариф;
3. внести начальные показания;
4. регулярно вносить новые показания;
5. использовать только корректные возрастающие показания.

Важно:

- показания не должны уменьшаться;
- активные дубли показаний на одну дату недопустимы;
- начисления формируются только на основании допустимых показаний.

### 5. Работа с начислениями и платежами

Администратор или бухгалтер может:

- создать начисление по участку или члену товарищества;
- зарегистрировать платеж;
- контролировать баланс;
- отслеживать долг и переплату.

Логика учета:

- долг определяется разницей между начислениями и оплатами;
- переплата учитывается как аванс;
- платеж может покрывать несколько начислений.

### 6. Работа с расходами

В разделе расходов можно:

- создавать расход;
- редактировать расход;
- отменять расход без физического удаления;
- учитывать отдельные категории расходов.

## Что доступно обычному пользователю

В `Личном кабинете` пользователь видит:

- ФИО и контакты;
- количество активных участков;
- общую сумму начислений;
- общую сумму оплат;
- текущий баланс;
- список своих участков;
- переход к финансам по каждому участку.

Пользователь также может:

- изменить ФИО, телефон и email;
- изменить пароль;
- передать показания счетчика, если эта возможность доступна.

## Важные правила эксплуатации

- Не удаляйте финансовые данные, если они уже участвуют в истории учета.
- Архивируйте записи вместо физического удаления, где это предусмотрено.
- Проверяйте роли пользователя перед выдачей доступа.
- Для членов товарищества доступ должен быть только к собственным данным.
- Перед началом работы желательно заполнить тарифы, участки и владельцев.
- После массовых изменений проверяйте финансовую сводку и карточки участков.

## Рекомендуемый порядок ежедневной работы

### Для администратора

1. проверить доступность системы;
2. поддерживать пользователей и роли;
3. следить за корректностью структуры данных.

### Для бухгалтера

1. проверить показания и начисления;
2. зарегистрировать новые платежи;
3. сверить долги, переплаты и расходы;
4. контролировать итоговые суммы в разделе `Финансы`.

## Где что искать

- общий вход: `Главная` → `Вход`;
- данные члена товарищества: `Администрирование` → `Члены товарищества`;
- данные участка: `Администрирование` → `Участки`;
- финансы: `Администрирование` → `Финансы`;
- показания члена товарищества: `Личный кабинет` или `Электроэнергия`.
