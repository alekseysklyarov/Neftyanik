# Публичная страница и заявки DachaHub

## Адреса

- `/` — публичная страница продукта, возможности, стоимость по запросу и порядок подключения.
- `/Product/Demo` — выбор страницы и роли в рабочем тестовом товариществе; вход без регистрации и пароля.
- `/Product/Management` — отдельная галерея для бухгалтера (финансовый обзор, расходы) и администратора (участники, участки). Под каждым предпросмотром доступен вход прямо в показанный раздел с нужной ролью.
- `/Product/Try/...` — страницы тестового товарищества с отдельной учебной базой посетителя. Данные можно изменять.
- `/Product/Request` — форма запроса демонстрации и обсуждения подключения.
- `/Platform/Requests` — входящие заявки для действующего администратора платформы. Доступ администратора отдельного товарищества не подходит.
- `/neftyanik/` и адреса других товариществ — прежние страницы входа. Общий адрес `/` больше не перенаправляет в «Нефтяник».

Публичные страницы доступны на украинском, русском и английском. Выбранный язык передаётся между публичными страницами в параметре `culture`.

## Тестовое товарищество

С первого экрана доступны две явные кнопки: «Войти в кабинет» под подписью «Уже зарегистрированы?» и «Попробовать без регистрации» для тестового товарищества. Вход в кабинет ведёт на существующую страницу входа «Нефтяника». Галерея открывает личный кабинет, показания электроэнергии, финансовый обзор или список участников с соответствующей ролью.

Для каждого браузера создаётся отдельная SQLite-база в памяти процесса, заполненная только вымышленными участниками, участками, начислениями, платежами и показаниями. Обычная база SQL Server не используется для операций демо. Сессия живёт 30 минут с момента создания; переходы между ролями этот срок не продлевают. По окончании вход в старую сессию закрывается, а база освобождается после завершения текущих запросов (очистка запускается раз в минуту). Следующий вход создаёт исходные данные заново. Есть кнопка немедленного перезапуска. Перезапуск приложения также удаляет все учебные сессии.

Демо использует отдельную cookie `DachaHub.Demo`; она не авторизует посетителя в настоящем товариществе или панели платформы. Разделы платформы и обычные страницы управления входом недоступны внутри демо. Для выхода из настоящего аккаунта сохраняется обычный механизм Identity.

Ограничение: 15 входов/переключений роли с одного IP за 15 минут, до 40 одновременно хранимых учебных сессий. Вместимость настраивается через `PublicDemo:MaxSessions` (1–100). При нескольких процессах сервера требуется закрепление посетителя за одним процессом; общий кластерный склад сессий не реализован. SQLite используется только для демо; представление дробных чисел адаптировано для её агрегатных запросов, точные финансовые данные основной системы остаются в SQL Server.

Галерея содержит 18 настоящих JPEG-скриншотов: шесть разделов на русском, украинском и английском языках в `wwwroot/images/demo/`. Снимки получены из учебного товарищества, персональные данные рабочего товарищества не используются. Изображения можно увеличить; отдельная кнопка открывает показанный раздел в изменяемом демо с нужной ролью. После изменения интерфейса снимки следует обновить. Главная и галерея проверены в браузере на широком экране и на ширине телефона 390 px.

## Приём и обработка заявок

Форма сохраняет имя, название товарищества, email, необязательные число участков и сообщение, время подачи в UTC и версию согласия `demo-contact-v1`. Данные находятся в отдельной таблице `DemoRequests` и не создают аккаунт, товарищество или подписку. Они доступны только администраторам платформы через защищённую страницу. Персональные данные не передаются в URL подтверждения.

Оператор открывает «Заявки», связывается с клиентом самостоятельно и нажимает «Отметить: связались». Раздел «Связались» хранит обработанные заявки; их можно вернуть в новые. Письма и уведомления автоматически не отправляются — входящие нужно проверять в панели платформы.

Форма использует серверную проверку полей, защиту от поддельных запросов, скрытое поле для отсечения простых ботов и лимиты: 5 отправок с одного IP за 15 минут и 100 отправок в целом за 15 минут. Просмотр формы не расходует лимит. За доверенным прокси необходимо использовать существующую конфигурацию ForwardedHeaders, иначе посетители могут разделять один IP-лимит.

## Подготовка базы

Перед запуском новой версии примените миграцию `20261016135200_AddDemoRequests` обычным процессом развёртывания. Она создаёт только таблицу заявок и индекс, не меняя финансовые таблицы.

```powershell
dotnet ef database update --project src/Neftyanik.Portal.Infrastructure --startup-project src/Neftyanik.Portal.Web --context ApplicationDbContext
```

Команду выполняют с настройками нужного окружения. При разработке приложение уже применяет миграции при запуске. В остальных окружениях автоматические миграции отключены.

Слово `product` зарезервировано для публичных страниц. Миграция SQL Server остановится, если товарищество уже использует такой адрес: сначала нужно согласовать и изменить его адрес. Не публикуйте новую версию до успешного применения миграции.

При подготовке изменения рабочая база не обновлялась.

## Коммерческие условия

До утверждения цен на странице указана «Стоимость по запросу». Числовые тарифы, бесплатный период и сроки ответа не обещаются. Заявка не создаёт подписку и не принимает оплату. Прямой приём банковских платежей не реализован. Формат переноса данных, сроки подключения и объём сопровождения согласовываются с клиентом.

Перед публичным запуском владельцу нужно определить ответственного за заявки и правила хранения контактов, утвердить коммерческие условия и оформить документы с реквизитами оператора сервиса.
