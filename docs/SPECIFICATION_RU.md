# Спецификация приложения

## Портал садового товарищества «Нефтяник»

### Назначение

Приложение на Razor Pages предназначено для ведения:

- пользователей и ролей;
- участков и владения;
- показаний общего счётчика товарищества;
- счётчиков и показаний членов товарищества;
- начислений, платежей и распределений;
- расходов, документов, новостей и настроек.

### Роли

- `Administrator` — управляет пользователями, ролями, участками и настройками;
- `Accountant` — ведёт показания, начисления, платежи и расходы;
- `Member` — просматривает свои данные и передаёт показания по своим счётчикам.

### Текущая модель электроэнергии

#### Общий счётчик товарищества

- `AssociationElectricityReading` хранит двухзонные показания общего счётчика;
- `AssociationElectricityTariff` хранит дневной и ночной тариф поставщика;
- `AssociationElectricityService` использует только `AssociationElectricityTariff`;
- по подтверждённым данным создаётся расход `Expense`.

#### Счётчики членов товарищества

- `MemberElectricityMeter` — однотарифный счётчик члена товарищества;
- `MemberElectricityMeterPlot` связывает один счётчик с одним или несколькими участками этого члена;
- `MemberElectricityReading` хранит показания и расчёт начисления;
- `MemberElectricityTariff` хранит историю однотарифных ставок;
- начисление сохраняется через связь `MemberElectricityReading -> Charge`.

### Финансовые правила

- физическое удаление финансовых данных не используется;
- `PaymentAllocation` связывает платежи и начисления;
- общий счётчик создаёт только `Expense`;
- счётчики членов создают только `Charge`.

### База данных

Чистая схема должна содержать только текущие таблицы Identity, владения, финансов и сохранённой модели электроэнергии.
